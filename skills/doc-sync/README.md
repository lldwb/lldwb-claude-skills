# doc-sync

文档与代码同步的标准工作流：由文档定位到对应代码，确认真实行为后同步更新文档 / 修正错误描述，只改与本次变更相关的部分，改完用只读子代理复核一致性。

## 使用

用户要求"根据文档找到对应代码、确认变更后同步更新文档""确保文档与代码实际行为一致"，或指出文档有错误、过期、与代码不符时自动触发；也可显式要求"用 doc-sync skill 同步这批文档"。

## 能力

- 两个入口：由文档找代码（更新）/ 由变更点反查受影响文档（修正），流程与复核一致
- 约束：只更新相关文档、不扩大范围、不写未实现的功能、格式遵循项目现有规范、不确定项交用户确认
- 复核：`Agent` 工具调度只读子代理（`references/verify-agent.md`），返回「文档位置 / 代码位置 / 是否一致 / 证据」清单；主代理核对证据后再采纳
- 边界：只改文档不改代码（代码问题转 `fix-bug`）

## 文件

- `SKILL.md` — 技能指令（唯一入口）
- `references/verify-agent.md` — 文档一致性复核子代理提示词模板（逐条核对，只读不改）

## 依赖

- 子代理调度能力（`Agent` 工具，`subagent_type: general-purpose`）
