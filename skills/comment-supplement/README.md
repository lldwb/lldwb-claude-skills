# comment-supplement

注释补齐与修正的标准工作流：补全缺失的类/方法/字段注释，修正不准确、过期、与代码实际行为不符的描述；**改动严格限定在注释层面**，不确定项先交用户确认。

## 使用

用户要求"补全缺失的注释""修正注释中与代码不符的描述"时自动触发；也可显式要求"用 comment-supplement skill 补齐这批文件的注释"。

## 能力

- 三类标记：缺失 / 不准确 / 过期，逐文件审查后按确认结果处理
- 铁律：不改业务逻辑、签名、注解与默认值；无法判断意图的进不确定清单，不臆测
- 自检：`git diff` 逐块确认改动都落在注释内、`git diff -w` 辅助、编译验证未破坏语法
- 边界：发现代码缺陷单独报告（需修复转 `fix-bug`）；改动仅限注释层面时用本技能，注释问题与逻辑/结构改动并存时用 `fix-bug`

## 文件

- `SKILL.md` — 技能指令（唯一入口）

## 依赖

- git；项目构建工具（自检时编译验证，命令以仓库 `AGENTS.md` 为准）
