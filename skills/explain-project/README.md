# explain-project

结合具体项目讲解概念的工作流：先读项目代码与文档，再逐项结合项目实际讲清楚（引用真实文件与代码位置，不泛泛而谈），输出 Markdown，结尾说明这是什么项目。

## 使用

用户说"我不懂如下内容，给我讲清楚""结合这个项目讲讲 X""这块是怎么实现的，讲一下"时自动触发；也可显式要求"用 explain-project skill 讲解"。

## 能力

- 讲解结构：它是什么 → 在本项目怎么落地 → 关键代码位置（`file:line`）→ 常见坑与约定
- 要求：区分通用知识与本项目特有约定；不臆造，无依据处明确标注
- 输出：标题 + Markdown 分点正文 + 结尾"这是什么项目"（定位、技术栈、核心模块）
- 边界：只产出讲解内容不改代码（要沉淀为文档转 `doc-sync`）

## 文件

- `SKILL.md` — 技能指令（唯一入口）

## 依赖

- 无（仅需读取项目代码与文档）
