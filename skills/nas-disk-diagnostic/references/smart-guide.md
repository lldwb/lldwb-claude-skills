# SMART 指标解读参考

## 关键预故障指标（Pre-fail）

这些指标异常通常意味着硬盘即将故障或已故障。

### ID 5: Reallocated_Sector_Ct（已重映射扇区数）

- **含义**：硬盘发现的坏扇区，已被重映射到备用扇区池
- **健康值**：0
- **预警阈值**：>10 需密切关注，>100 高风险
- **不可修复**：持续增长说明盘片表面持续恶化
- **解读**：这个值只会增不会减，代表硬盘已发生物理介质损坏

### ID 197: Current_Pending_Sector（当前待处理扇区数）

- **含义**：读取失败的扇区，等待被重映射（硬盘尚未确认完全损坏）
- **健康值**：0
- **预警阈值**：>10 需关注，>1000 通常不可安全修复
- **可修复性**：少量（个位数）有可能通过 `badblocks -w` 或厂商工具修复；大量则不可修复
- **解读**：这是判断坏盘可修复性的核心指标

### ID 198: Offline_Uncorrectable（离线不可纠正扇区数）

- **含义**：离线扫描时发现的不可纠正扇区
- **健康值**：0
- **预警阈值**：任何 >0 都需警惕
- **不可修复**：>0 表示盘片物理损坏，通常与 ID 197 同步增长
- **解读**：与 197 配合判断，两者都高则硬盘不可修复

## 错误统计指标

### ID 187: Reported_Uncorrect（报告的不可纠正错误）

- **含义**：控制器无法使用 ECC 纠正的错误次数
- **健康值**：0
- **解读**：>0 表示已发生不可恢复的读取错误

### ID 188: Command_Timeout（命令超时）

- **含义**：因硬盘超时中止的命令次数
- **健康值**：0 或极低
- **解读**：异常高值（如上亿次）通常伴随盘体故障；也可能是 SATA 线缆问题

### ID 199: UDMA_CRC_Error_Count（UDMA CRC 错误数）

- **含义**：数据传输过程中的 CRC 校验失败次数
- **健康值**：0
- **解读**：**通常不是盘体故障，而是 SATA 线缆接触不良**。更换线缆后此值不再增长（但累计值不会清零）。

## 使用量指标

### ID 9: Power_On_Hours（通电小时数）

- **含义**：硬盘累计通电时间
- **换算**：8760 小时 = 1 年（24x7 运行）
- **风险评估**：
  - <20000h：正常服役期
  - 20000-40000h：进入老化期，需加强监控
  - >40000h：高风险期，建议预防性更换
  - >50000h：超期服役，故障概率显著上升

### ID 12: Power_Cycle_Count（电源循环次数）

- **含义**：开关机次数
- **解读**：频繁开关机会加速硬盘机械部件磨损

### ID 4: Start_Stop_Count（启停次数）

- **含义**：主轴电机启停次数
- **解读**：与 Power_Cycle_Count 类似，频繁启停影响寿命

## 温度指标

### ID 194: Temperature_Celsius（温度）

- **健康范围**：<45°C
- **预警**：45-55°C 需改善散热
- **危险**：>55°C 加速盘片老化，>60°C 可能触发降速保护
- **注意**：smartctl 通常会显示 Min/Max 历史值，Max 值反映历史最高温度

### ID 190: Airflow_Temperature_Cel（气流温度）

- **含义**：进风口温度，反映机箱散热状况
- **解读**：与 ID 194 配合判断散热问题来源

## 机械指标

### ID 1: Raw_Read_Error_Rate（原始读取错误率）

- **解读**：Seagate 盘此值通常很高（数千万），这是 Seagate 的特性，不代表故障；HGST/WD 盘此值为 0 才正常

### ID 7: Seek_Error_Rate（寻道错误率）

- **解读**：与 ID 1 类似，Seagate 盘原始值可能很高，需看标准化值（VALUE/WORST 是否高于 THRESH）

### ID 192: Power-Off_Retract_Count（断电磁头缩回次数）

- **解读**：异常断电导致，频繁发生可能损坏磁头

## 判断流程

```
硬盘掉线?
├─ 是 → 尝试 rescan
│   ├─ 成功识别 → 检查 SMART
│   │   ├─ 197=0 且 198=0 → 可重新加入阵列
│   │   ├─ 197>0 或 198>0 但 <100 → 跑长自测，通过则可用
│   │   └─ 197>1000 或 198>1000 → 不可修复，物理更换
│   └─ 失败 → 硬盘或控制器损坏，物理更换
└─ 否 → 常规 SMART 巡检
    ├─ 199>0 且不增长 → 检查线缆（非盘体故障）
    ├─ 5>0 → 盘片开始损坏，制定更换计划
    ├─ 9>40000 → 老化盘，预防性更换
    └─ 温度>55 → 改善散热
```

## 品牌特性差异

- **Seagate**：ID 1 和 ID 7 的 RAW_VALUE 通常为极大数（数千万到数亿），这是 Seagate 的算法特性，不代表故障。看 VALUE/WORST 标准化值是否高于 THRESH。
- **HGST/WD**：ID 1 和 ID 7 的 RAW_VALUE 为 0 才正常，>0 通常确有问题。
- **SSD**：SMART 属性与 HDD 不同，关注 ID 5（重分配）、ID 9（通电）、ID 12（开关机）、ID 177（Wear Leveling）、ID 179（保留块）、ID 231（SSD 寿命指示）。
