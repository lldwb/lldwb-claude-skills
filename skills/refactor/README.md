# refactor

重构（结构改造、对外行为不变）的标准工作流：先立契约与测试基线、再改代码；改造与审查分离（独立只读子代理对抗性审查）；按「编译 → 审查 → 测试」循环验证；输出重构报告并按规范提交 git。

## 使用

用户要求重构代码（分层/职责重构、实现迁移重写、结构性改造、批量同构改造）时自动触发；也可显式要求"用 refactor skill 重构"。

**边界**：小范围优化（可读性、重复代码抽取、局部性能）用 `code-optimize`；新增或改变对外行为用 `feature-dev`；缺陷修复用 `bug-fix`；需要多模块并行隔离执行时，本技能定"改什么与怎么验收"，`module-batch` 提供 worktree 并行机制。

## 能力

- **契约先行（SSOT）**：目标形态、范围与单元、不可变更项、命名归属、验证命令固化为一份契约文件，编排方与所有子代理加载同一份；契约确认前不改代码
- **基线先行**：改造前建立可复跑的测试基线（既有测试 / 契约级测试 / 契约快照降级），测试须满足「重构不变性」——只经对外契约交互，禁内部调用断言、禁替换被测装配
- **改造与审查分离**：改造子代理执行；未参与改造的独立只读子代理以对抗性立场审查，逐方法做「原逻辑 → 新逻辑」映射，输出分级报告
- **验证循环**：编译 → 审查 → 测试，任一步产生改动即回到编译重跑；默认最多 3 轮，超出交用户介入
- **失败分类**：既有无关失败记入失败集合、标注不阻断；本次引入的回归必须修复
- **契约快照比对**：`scripts/contract-snapshot.py` 机械抓取改造前后的对外契约痕迹（公开签名 / 路由与关键注解 / 导出符号）并输出差异清单，防"路径/签名/注解被悄悄改动"漏检（只取数，判定归 agent）
- **收尾报告**：改动清单、不可变更项核对、审查与修复记录、测试结果、重试与用户介入记录

## 文件

```
refactor/
├── SKILL.md                          # 技能指令（唯一入口）
├── README.md
├── scripts/
│   └── contract-snapshot.py          # 契约快照：capture 抓取 / diff 比对（只取数）
└── references/
    ├── contract-template.md          # 重构契约模板（SSOT：目标形态/不可变更项/验证命令）
    ├── test-baseline.md              # 基线测试与「重构不变性」规则、失败分类
    ├── agent-prompts.md              # 改造 / 对抗性审查 / 修复 三份子代理提示词模板
    └── report-template.md            # 重构报告模板
```

## 依赖

仅 Python 3 标准库（`contract-snapshot.py`），无三方依赖。
