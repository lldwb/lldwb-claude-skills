# module-batch

多模块并行改造/批量任务：为每个待处理模块创建一个独立 git worktree，各起一个子代理在 worktree 内直接完成模块改造任务（修改代码、执行测试、按容错条款处理失败、按门禁验收后提交），全部完成后合并回主分支并按规范提交。

## 使用

用户要求"按模块批量改造/处理多个模块"、"多模块并行执行任务"、"按工作树隔离并行开发"时自动触发。

## 能力

- 阶段 0 前置检查（工具/资源/依赖/git 起点/任务说明完备性）→ 阶段 1 并行子代理（`run_in_background` + 轮询）→ 阶段 2 合并（公共文件冲突取并集）→ 阶段 3 收尾（删 worktree 留分支）
- 子代理是唯一执行者（不借助外部 AI CLI），prompt 必须自包含（worktree 路径 + 模块路径 + 任务说明 + 提交规则）
- 经验教训速查：任务说明缺失门禁→子代理只做核心工作、公共文件并发冲突、测试凭据不一致、测试基类编码乱码等
