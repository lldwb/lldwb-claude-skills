# session-summary

会话总结与 skills 迭代：把一次会话收尾为「做了什么 → 发现的问题与教训 → 当前 skills 优化点评估 → 实施」，作为迭代本仓库技能的工具。

## 用法

当用户要求"总结这次会话""看看 skills 有没有可优化的地方""把这次的经验沉淀进技能"时触发。

## 文件与依赖

| 文件 | 说明 |
|------|------|
| `SKILL.md` | 执行指令（取证 → 总结 → 审视 skills → 优化点清单 → 确认后实施） |

无脚本依赖；实施阶段按改动性质转 `feature-dev` / `bug-fix` / `refactor`，发版走仓库既有规则。
