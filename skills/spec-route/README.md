# spec-route

规范路由的标准工作流：项目约定以 `AGENTS.md` 为唯一权威源，本技能只做「场景 → 章节」的定位与按段加载，不复制约定内容。

## 使用

用户要求"按项目约定查某类改动的要求""确认这种写法是否合规""这条约定在 `AGENTS.md` 哪一节"时自动触发；也可显式要求"用 spec-route skill 定位约定章节"。

**边界**：约定与代码不一致、需要对齐用 `doc-sync`；修订约定本身直接改 `AGENTS.md`；读懂某段实现用 `project-explain`。

## 能力

- 路由表：场景 → 章节序号 → 章节锚点标题（Grep 用）→ 关键约定关键词；按需加载、随使用回填
- 按段读取：Grep 定位章节标题取行号 → Read + `offset/limit` 只读目标段，不全文加载 `AGENTS.md`
- 引用给出处：每条约定附 `文件:行`，归属明确指向 `AGENTS.md`
- 校验口径：来源可复现（同命令复现同一段落）、无越界（不新增 / 概括约定）、未命中如实说明
- 边界：不改 `AGENTS.md` 正文、不改代码；一个路由表对应一个项目，不跨项目复用

## 文件

- `SKILL.md` — 技能指令（唯一入口）
- `references/route-table-template.md` — 路由表模板、填充步骤、读取指引与输出格式

## 依赖

- 无（仅需读取项目 `AGENTS.md`；Grep / Read 工具即可）
