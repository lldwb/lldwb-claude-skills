# spec-route

开发规范路由的标准工作流：项目的开发手册/规范文档是唯一权威源，本技能只做「场景 → 章节」的路由与按段加载，不复制规则内容。

## 使用

用户要求"按项目开发规范查某类改动的要求""确认这种写法是否合规""这条规范在哪一章"时自动触发；也可显式要求"用 spec-route skill 定位规范章节"。

**边界**：规范与代码不一致、需要对齐用 `doc-sync`；修订规则本身直接改权威源文档；读懂某段实现用 `project-explain`。

## 能力

- 路由表：场景 → 章节序号 → 章节锚点标题（Grep 用）→ 关键约束关键词，按需加载、随使用回填
- 按段读取：Grep 定位章节标题取行号 → Read + `offset/limit` 只读目标段，不全文加载手册
- 引用给出处：每条约束附 `文件:行`，规则归属明确指向权威源
- 校验口径：来源可复现（同命令复现同一段落）、无越界（不新增/概括规则）、未命中如实说明
- 边界：不改规范正文、不改代码；一本手册对应一个路由表，不跨项目复用

## 文件

- `SKILL.md` — 技能指令（唯一入口）
- `references/route-table-template.md` — 路由表模板、填充步骤、读取指引与输出格式

## 依赖

- 无（仅需读取项目文档与代码；Grep / Read 工具即可）
